Generate an endpoint:
1. Navigate to [beeceptor](https://beeceptor.com/) and create a mock server to simulate API endpoint behaviour
2. Make sure to append the server with your initials to avoid clashes with other participants' servers.

Create a webhook:
1. Navigate to `Account Settings` → `Webhooks` and `Create webhook`
2. Add relevant details and paste the beeceptor endpoint you created

Test the webhook:
1. Click the button to test the webhook
2. Navigate to [beeceptor](https://beeceptor.com/) to see the notification
3. Check your dbt account to ensure your webhook is doing what it should
