Generate an endpoint:
1. Navigate to [beeceptor](https://beeceptor.com/) and create a mock server to simulate API endpoint behaviour
2. Make sure to append the server name with `_firstlast` as with the branch name to avoid clashes with other participants' servers

Create a webhook:
1. Navigate to `Account Settings` → `Webhooks` and `Create webhook`
2. Add relevant details and paste the beeceptor endpoint you created
3. `Save` and `Test endpoint`; navigate to [beeceptor](https://beeceptor.com/) to see the notification

Test the webhook:
1. Perform the action in your webhook
2. Navigate to [beeceptor](https://beeceptor.com/) to see the webhook in action!
